## Part B — Python assembler

`PartB_Assembler/assembler.py` implements a two-pass Hack assembler. It strips comments and blank lines, resolves labels on the first pass, assigns variables starting at RAM address 16, and emits 16-bit machine instructions on the second pass.

For K = 38, `38 % 3 = 2`, so the required extra feature is a warning when a label is defined more than once. The assembler warns and retains the first definition.

From the `capstone/` directory, assemble the Part C program:

```bash
python3 PartB_Assembler/assembler.py PartC_Box/Box.asm PartC_Box/Box.hack
```

Run the duplicate-label test:

```bash
python3 PartB_Assembler/assembler.py \
  PartB_Assembler/tests/DupLabel_Test.asm \
  PartB_Assembler/tests/DupLabel_Test.hack
```

Expected warning (line number may depend on edits to the test file):

```text
Warning: Line 5: label 'LOOP' is already defined; keeping its first definition at address 0.
```

## Part C — Box program

`PartC_Box/Box.asm` checks the memory-mapped keyboard and draws or clears a rectangle:

- Starting row: 38
- Height: 20 rows
- Width: 48 pixels (3 Hack screen words per row)
- First screen word: `16384 + (32 * 38) = 17600`

`PartC_Box/Box.hack` is generated by the included Python assembler. Load it into the CPU Emulator and verify the key-press/key-release behavior before claiming the visual test is complete.
